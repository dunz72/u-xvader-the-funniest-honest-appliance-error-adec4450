# The Funniest Honest Appliance Error

One line, at most 200 characters: an honest error message from a washing machine that has genuinely given up on an unbalanced load. When every towel migrates to one side of the drum, a real washer really does shake violently, abort the spin, and wait for someone to redistribute the load — this entry just lets the machine say so, in its own exasperated voice. Funny because it is true, not because anything was invented.
